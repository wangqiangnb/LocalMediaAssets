# LocalMediaAssets

一个 Jellyfin 插件，解决使用中的三个问题：

1. **演员信息和照片的存储问题**——演员照片和简介保存在视频目录 `actors/` 或演员库中，随媒体文件一起迁移，换电脑或移动硬盘后无需重新刮削；Jellyfin 刮削到的演员图片也会自动保存到本地素材库。
2. **影片详情页的预览图和视频显示**——详情页展示「预览图片和剧照」「预告片」区块：剧照点击放大浏览，预告片点击弹窗播放，区块顺序可在设置中调整。
3. **演员部分的重新设计（解决原版一直转圈的问题）**——用本地素材圆形卡片替换 Jellyfin 原版演员区：绿光 = 可进入演员详情页（有简介、库中有其他参演作品，或有多张照片）；红光 = 本地暂无内容，点击头像触发 Jellyfin 刮削，成功后自动变绿。原版演员区在无本地素材时会一直转圈等待网络刮削，本插件改为有素材立即显示、无素材点击才刮，并支持查看演员简介、照片管理和参演作品。

本插件不负责刮削，只负责把你已有的演员素材整理、显示出来。

---

## 安装

1. 从 GitHub Releases 下载最新版：<https://github.com/wangqiangnb/LocalMediaAssets/releases>
2. 停止 Jellyfin。
3. 将压缩包中的 `Jellyfin.Plugin.LocalMediaAssets.dll` 放入插件目录：
   - Windows：`C:\Users\<你的用户名>\AppData\Local\jellyfin\plugins\LocalMediaAssets\`
   - Docker / Linux：`<配置目录>/plugins/LocalMediaAssets/`
4. 启动 Jellyfin。

升级版本：停止 Jellyfin，用新版 DLL 覆盖旧文件，重启即可，设置会保留。

## 使用

### 设置

打开 `http://localhost:8096/LocalMediaAssets/config`：

- 管理员可配置「演员数据库」（存储方式、路径、同步方式）和「影视详情页优化」；
- 普通用户只能查看数据库状态，并设置自己的「影视详情页优化」。

默认设置可直接使用。如需集中管理演员素材，可在设置中指定「演员库」目录。

### 素材放置

素材放在媒体文件夹中，文件名需与演员名一致：

```
媒体库/
└─ 电影A (2020)/
    ├─ 电影A.mkv
    ├─ extrafanart/        ← 剧照
    │   ├─ 1.jpg
    │   └─ 2.jpg
    ├─ trailers/           ← 本地预告片（可选）
    └─ actors/             ← 演员照片与简介（可选）
        ├─ 张三.jpg
        └─ 张三.json       ← {"name":"张三","overview":"简介"}
```

- 照片也可放在影片或剧集根目录，文件名与演员名一致即可识别。
- 设置「演员库」目录后，插件会按演员名首字自动分文件夹存放。
- 如需使用外部整理好的照片，可放入「外部演员库」目录，在设置页点击「手动同步演员库」，重复照片会自动跳过，删除过的照片不会再次加入。

### 详情页效果

打开任意电影或剧集详情页：

- 「预览图片和剧照」「预告片」「演员」区块按设置中的顺序显示；
- 点击剧照可放大，点击预告片弹窗播放；
- 演员卡片绿光可进入演员详情页；红光时点击头像触发刮削，完成后变绿。

## 常见问题

**演员卡片是红光，点击没有反应？**
本地没有该演员的素材。点击头像会触发 Jellyfin 刮削，成功后变绿；如长时间无变化可再次点击。

**换电脑后演员照片丢失？**
将媒体文件夹和演员库目录一同拷贝到新机器，安装插件后将「演员库路径」指向该目录，再扫描媒体库即可。

**卸载插件是否影响 Jellyfin？**
不会。插件仅在 `jellyfin-web/index.html` 中注入一行带标记的脚本；卸载时自动移除，也可在设置页点击「恢复 Jellyfin 界面文件」手动移除，不影响其他插件。

**详情页没有「预览图片和剧照」区块？**
确认媒体文件夹中存在 `extrafanart/`，或在设置中开启「自动读取视频目录照片」，并强制刷新浏览器（Ctrl+Shift+R）。

## 隐私
