# LocalMediaAssets — 让演员照片和剧照跟着媒体走

一个 **Jellyfin 10.11（.NET 9）** 插件，解决两个最常见的问题：

1. **换电脑 / 移动硬盘迁移后，演员照片和简介全丢了**——本插件把演员素材保存在媒体文件旁边，跟着硬盘走，不用重新刮削；
2. **详情页看不到剧照/预告片**——本插件在电影、剧集详情页展示「预览图与视频」区块，点击即可放大看图、弹窗播放预告片。

> 不会刮削？没关系——**本插件不负责刮削**，它负责把别人刮削好的演员素材整理到本地。

---

## ✨ 主要功能

| 功能 | 说明 |
|---|---|
| 🖼️ **演员照片本地化** | 演员照片从视频目录 `actors/` 或「演员库」读取，不依赖网络 |
| 📝 **演员信息本地化** | 读取 `actors/<演员名>.json` 作为演员简介 |
| 🎬 **详情页预览图与预告片** | `extrafanart/` 剧照以网格展示，本地/在线预告片弹窗播放 |
| 📦 **演员库（默认源）** | 统一管理所有演员照片/简介，自动同步到各视频目录 |
| 📄 **NFO 自动补写** | 为没有 NFO 的电影/剧集补写 `movie.nfo`（含演员列表），换机器 cast 不丢 |
| ⏰ **计划任务** | 「整理本地演员信息和照片」：手动 / 每天 4 点 / 扫描后自动执行 |
| 👥 **每用户显示偏好** | 每个用户可单独设置：是否显示剧照、位置、语言等 |
| 🌐 **中英双语** | 界面语言跟随 Jellyfin 或手动指定 |

## 🚀 快速开始（5 分钟上手）

### 第 1 步：安装插件

1. **停止** Jellyfin（任务栏托盘图标退出，或任务管理器结束 `jellyfin.exe`）
2. 找到 Jellyfin 的插件目录：
   - Windows：`C:\Users\<你的用户名>\AppData\Local\jellyfin\plugins\`
   - Docker/Linux：`<配置目录>/plugins/`
3. 在里面新建文件夹 `LocalMediaAssets`，把 `Jellyfin.Plugin.LocalMediaAssets.dll` 放进去
4. **启动** Jellyfin

> 无需修改任何 Jellyfin 文件。插件启动时会自动完成所有设置。

### 第 2 步：打开设置页

浏览器访问（把 `服务器地址` 换成你的，如 `http://localhost:8096`）：

```
http://<服务器地址>/LocalMediaAssets/config
```

管理员可以看到全部设置；普通用户只能看到「我的显示偏好」。

**建议先设置：**「演员库目录路径」（可选，例如 `D:\演员库`），保存。

### 第 3 步：放置素材

在媒体文件夹里按下面的结构放素材（没有也不影响插件运行）：

```
媒体库/
├─ 电影A (2020)/
│   ├─ 电影A.mkv
│   ├─ extrafanart/           ← 剧照（命名随意，1.jpg、2.jpg…）
│   │   ├─ 1.jpg
│   │   └─ 2.jpg
│   └─ actors/                ← 演员照片 + 简介（可选）
│       ├─ 张三.jpg           ← 文件名必须和演员名一致
│       └─ 张三.json          ← {"name":"张三","overview":"简介"}
└─ 剧集B/
    ├─ tvshow.nfo
    ├─ extrafanart/
    └─ trailers/              ← 本地预告片（可选）
```

> 💡 演员照片不一定要放在 `actors/` 文件夹里——**直接放在影片根目录、剧集根目录等任意位置都行**，只要文件名和演员名一致（如 `张三.jpg`）就会被识别。

**演员库目录**（可选，在设置页配置路径后由插件自动生成）：

```
演员库/
└─ People/
    ├─ 张/张三.jpg、张三.json      ← 按首字符分组（拉丁按大写首字母，其余归 Other）
    ├─ L/Leonardo DiCaprio.jpg
    └─ Other/…
```

### 第 4 步：运行整理任务

仪表盘 → **计划任务** → 「整理本地演员信息和照片」→ 点「运行」。

（或者对媒体库执行一次扫描，也会自动整理。）

### 第 5 步：查看效果

打开一部电影/剧集的详情页：

- 出现「**预览图与视频**」区块（位置可在设置里调：顶部 / 简介上方 / 演员上方 / 底部）
- 点击剧照 → 灯箱放大浏览（左右键切换）
- 点击预告片 → 弹窗播放（不跳转页面）
- 演员页 → 本地照片和简介

## ⚙️ 设置说明

### 管理员可以设置（影响所有人）

- **演员库目录路径**：插件保存演员照片/简介的权威目录
- **演员库优先**：不一致时以演员库为准（默认开）
- **演员照片/信息本地化开关**
- **整理与导出选项**：导出到演员库、同步到视频目录、补写 NFO
- **预览图与预告片**：显示开关、剧照来源（extrafanart/视频目录/海报图）、默认位置、数量上限
- **界面语言**：跟随 Jellyfin / 中文 / English

### 普通用户可以设置（只影响自己）

- 是否显示剧照、是否显示预告片
- 剧照位置、界面语言、最多剧照数

## 💾 换电脑 / 移动硬盘迁移指南

1. 把媒体库（视频 + `extrafanart/` + `actors/` + NFO）和「演员库」目录一起拷到移动硬盘
2. 新电脑装好 Jellyfin 和本插件（第 1 步）
3. 设置页把「演员库目录路径」指到移动硬盘上的演员库
4. 添加媒体库 → 扫描

**结果**：演员照片、简介、cast 全部从本地恢复，**不需要重新刮削**。

## 🐳 Docker / Linux 部署

插件 DLL 直接放进容器的插件目录即可。**注意**：容器内 `jellyfin-web` 目录可能没有写权限，导致详情页剧照不可用。解决办法（任选）：

```bash
# 方法一：给 index.html 写权限（简单）
docker exec -u 0 <容器名> chmod 666 /jellyfin/jellyfin-web/index.html

# 方法二：设置 JELLYFIN_WEB_DIR 指向可写目录
# 在 docker-compose 的 environment 里加：
#   JELLYFIN_WEB_DIR=/config/jellyfin-web
# 并把镜像里的 jellyfin-web 拷到 /config/jellyfin-web
```

> 即使不解决，演员照片/简介本地化、整理任务、设置页等**其他功能全部正常**。

## ❓ 常见问题

**Q：详情页没有「预览图与视频」区块？**
A：①确认媒体文件夹有 `extrafanart/`（或开启「自动读取视频目录照片」）②访问 `http://<地址>/LocalMediaAssets/verify?itemId=<你的条目ID>` 验证管线 ③强刷浏览器（Ctrl+Shift+R）。

**Q：换机器后演员列表没了？**
A：开启「为没有 NFO 的电影补写 movie.nfo」，或开启 Jellyfin 原生「保存媒体信息到文件夹」，cast 随 NFO 走。

**Q：同一个演员在不同视频里照片不一样？**
A：配置演员库目录并运行整理任务，以演员库为默认源统一所有副本。

**Q：普通用户打不开设置？**
A：设置页对普通用户只显示「我的显示偏好」；管理员设置需用管理员账号登录。

## 🔒 隐私说明

- 插件**零遥测、零外部通信**，唯一的网络请求是下载 Jellyfin 库中已有的演员图片 URL；
- 不收集、不上传任何个人信息；
- 源码不包含个人路径（本机路径放在不入库的 `jellyfin.path.txt`）。
