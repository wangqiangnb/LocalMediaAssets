LocalMediaAssets 剧照管线验证页

此页面模拟 Jellyfin 详情页环境（含演员区 #castCollapsible）。

用法：/LocalMediaAssets/verify?itemId=<你的条目ID>

如何获取条目 ID：打开任意电影/剧集的详情页，浏览器地址栏 URL 形如 …#/details?id=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx，把 id= 后面那串复制到本页 ?itemId= 参数后，例如 /LocalMediaAssets/verify?itemId=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx。

请先补充 itemId 参数。

正常结果：下方红色框【模拟演员区】上方出现「预览图片和剧照」区 → 说明「脚本 → API → 渲染」整条链路正常。
